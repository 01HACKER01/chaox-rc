## what is this & what is teh purpose of it 
this is a transmitter and receiver made by arduino nano 2 joysticks and nrfl01 with antennas this is a 4 channel transmitter and receiver we can use it to controll anuything from far away without using a wire in between we can controll a rc car with this or a drone.

## Why it exists 
so i wanted to make a rc car but i wanted first to check if it will work like if i make it so firstly i thought lets make a rc transmitter and receiver than we will make a rc car.

## How to assemble 
u can just add all the comps on teh zero pcb and do the connections shown in teh schematics and than pug the arduino cable to the pcb and upload the code using arduino ide and than u are ready to use this.
